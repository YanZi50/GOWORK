# 局域网快传 LAN Share v2.3

本地局域网文件夹共享桌面软件：把选定文件夹变成共享文件夹，同一局域网内的电脑 / 手机 / 平板
**实时发现**并拉取（或往可写共享上传）。深色简洁界面，纯内网传输，数据不出局域网。

```
┌──────────────────────────────────────────────────────────────┐
│  主机（每台电脑都装桌面版）          局域网用户（浏览器即可）   │
│  ┌────────────────┐   UDP组播      ┌────────────────────┐     │
│  │ 拖拽/选择文件夹  │◄──广播──────►│ 实时发现设备         │     │
│  │ 公开/密码/私有   │   SSE推送     │ 浏览→下载 / 上传    │     │
│  │ 可上传/限速/托盘 │               │ 无需手动刷新        │     │
│  └────────────────┘               └────────────────────┘     │
└──────────────────────────────────────────────────────────────┘
```

## 快速开始（桌面版）

1. 双击 **`启动桌面版.bat`**（需已装 Python 3.10+，本机 3.14；首次运行会自动安装 PySide6）；
   **给其他电脑用：直接拷 `dist/局域网快传.exe`，对方双击即用，什么都不用装**。
2. 主界面右侧「管理」：填名称、点「选择…」选文件夹、设权限，勾选**可上传**即可允许对方传文件；
   或直接把文件夹从资源管理器**拖进拖拽区**立即共享。
3. 关闭窗口会**最小化到托盘**继续服务；**双击托盘图标唤出主界面**；托盘右键可勾选**开机自启**、或退出。
4. 其他设备：浏览器打开 `http://<主机IP>:8765`（界面二维码扫码即达），设备列表实时出现。

> 首次运行 Windows 防火墙会弹窗，请勾选「专用网络」并允许。
> 某些路由器开启「AP 隔离」时设备互不可见，请在路由器设置中关闭。

浏览器版（无桌面壳）仍可用：`启动局域网快传.bat` 或 `python server.py`。

## 功能

| 需求 | 实现 |
|---|---|
| 选定文件夹变共享 | 管理页添加任意本地文件夹；桌面版支持**拖拽文件夹**（Qt 层取绝对路径） |
| 权限 / 加密 | 每目录三档：**公开 / 密码保护**（SHA-256 加盐 + 会话令牌 + 登录限流 10 次/300s）/ **仅自己**；管理接口仅本机 |
| 对方可上传 | 共享可勾选「可上传」；上传走流式分块 + 原子落盘，**重名自动改名**（`名 (1).ext`），不覆盖原文件；浏览器直接拖文件进列表即可上传，带进度条 |
| 快速稳定 | `ThreadingHTTPServer` 多线程 + 64KB 分块流式传输 + Range 断点续传 + ZIP 打包 |
| **在线预览** | 图片 / 视频 / 音频 / PDF / 文本（txt/md/log 等）文件行点「预览」直接看，无需下载；超大文本自动停止加载并提示下载 |
| **下载统计** | 管理页「下载记录」：每个文件**被谁下载过（设备名/IP）、几次、何时**；已记录 = 已被别人拉走，避免误删还没被下载过的文件；数据落盘 `downloads.json`（exe 旁），SSE 实时刷新 |
| 速度显示 / 限速 | 顶栏实时显示 ↓下载/↑上传 速度（SSE stats 推送，1s 采样）；管理页可设**总限速**（KB/s，0=不限），对上下行同时生效 |
| 实时广播 | UDP 组播（3s 心跳/12s 判离线）+ SSE 推送，任何页面变更即时同步，前端事件总线（bus.js emit/on）驱动，**无需手动刷新** |
| 桌面体验 | 系统托盘常驻 + **双击托盘唤出** + 开机自启（注册表 HKCU Run）+ 单实例锁 + 原生文件夹对话框；窗口内即可打开其他设备；已移除 WebEngine 默认英文右键菜单 |
| 下载位置自选 | 桌面版下载文件时**弹窗选择保存位置**，不再静默存入"下载"文件夹 |
| 密码可见 | 密码保护共享，编辑时**明文回显自己设置的密码**（仅本机管理页可见，局域网设备只能看到"需要密码"） |
| 管理页简洁 | 已配置共享为**折叠卡片**：默认收起显示名称/路径/权限，点「编辑」展开修改（名称/路径/权限/密码/可上传/删除）；添加共享同样折叠 |
| 拖拽添加 | 把文件夹拖进窗口**自动填入路径**，不立即共享——确认设置后点「保存共享」才生效，避免误拖即共享 |
| 下载记录 | 显示谁下载过、几次、何时（**设备名 + IP**）；记录多时默认显示最近 20 条，可「显示全部」；可一键「清空记录」（只清统计，不动文件） |
| 高级设置 | 「管理」页独立折叠模块：开机自启、服务端口、数据目录位置、清空下载记录（托盘菜单不再重复） |
| 复制链接 | 多级剪贴板兜底（桌面端由系统剪贴板写入），点击即复制，不再无反应 |
| 端口独占 | 同一时间只有一个实例监听一个端口；再开程序自动换端口并提示，不会与已运行实例抢数据 |
| 亮/暗主题 | 顶栏一键切换深/浅色主题，选择自动记忆（localStorage） |
| 简单易懂 | 双击启动、中文界面、深色简洁 UI、拖拽即共享；共享卡片「打开」=进入文件夹，「复制链接」=复制直达链接（对方粘贴浏览器直接进入该共享） |

## 目录结构

```
lan-share/
├── server.py              # 服务内核（HTTP + UDP 组播 + SSE + 上传/限速/统计，仅标准库）
├── desktop.py             # 桌面壳（PySide6 + QtWebEngine：窗口/托盘/自启/拖拽/单实例）
├── smoke_test.py          # 冒烟测试（17 项：上传/限速/统计/可写/Range/SSE）
├── 启动桌面版.bat          # 桌面版一键启动（自动装依赖）
├── 启动局域网快传.bat      # 浏览器版一键启动
├── requirements.txt       # 桌面版依赖（PySide6）
├── static/
│   ├── index.html / style.css / app.js   # 单页深色界面
│   ├── bus.js             # 事件总线（emit/on）
│   ├── qrcode.min.js      # 二维码库（MIT，本地离线）
│   ├── qwebchannel.js     # Qt WebChannel 桥（BSD-3，本地离线）
│   └── favicon.svg
└── config.json            # 运行后自动生成（共享/限速配置持久化；exe 版存于 exe 旁）
```

## 安全说明（重要，请读完）

1. **明文 HTTP 边界**：默认 HTTP 传输，局域网内技术用户可抓包窃听密码与文件内容。
   敏感内容请启用 HTTPS：自备 `cert.pem` + `key.pem` 放到程序目录（exe 版为 exe 所在目录），
   重启自动启用（openssl 自签命令见下）。
2. **登录限流**：单 IP 300 秒内最多 10 次密码尝试；会话令牌 24h 有效。
3. **管理接口仅本机**：添加/删除/限速等管理操作仅限本机地址，局域网其他设备无法进入管理页。
4. **路径安全**：请求路径真实路径归一化校验，防 `../` 目录穿越；上传文件名做 basename 清洗。
5. **上传写操作边界**：仅在勾选「可上传」的共享内生效；重名自动改名、tmp+rename 原子落盘，
   传输中断不留残件；未勾选「可上传」的共享保持纯拉取。
6. 限速为全局令牌桶（上下行共享额度，首次突发一桶），局域网共享带宽紧张时建议设置。

```bash
# HTTPS 自签证书（可选）
openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 825 -nodes -subj "/CN=lan-share"
```

## 与主流开源方案的对比（为何自研）

| 工具 | 星标 | 许可 | 共享文件夹 | 每目录权限 | 局域网自动发现 | 备注 |
|---|---|---|---|---|---|---|
| [LocalSend](https://github.com/localsend/localsend) | ~56k | Apache-2.0 | ❌ 仅点对点发送 | ❌ | ✅ UDP 组播 | 无"文件夹挂出来让别人随时拉"的模型 |
| [filebrowser](https://github.com/filebrowser/filebrowser) | ~30k | Apache-2.0 | ✅ | ✅ 用户/角色 | ❌ | 需手动输入地址，无设备广播 |
| [HFS (rejetto)](https://github.com/rejetto/hfs) | — | 开源 | ✅ 虚拟文件系统 | ✅ 账户 | ❌ | 功能最全，需手动访问地址 |
| [ezshare](https://github.com/mifi/ezshare) | ~800 | MIT | ✅ 单目录 | ❌ | ❌ | 一次只能共享一个目录 |
| **本项目** | — | 原创 | ✅ 多目录 | ✅ 公开/密码/私有 | ✅ UDP 组播 + SSE | 需求组合无现成单工具覆盖 |

结论：现有开源工具要么"发送型"（LocalSend，无文件夹浏览）、要么"服务器型"
（filebrowser/HFS，无实时设备发现）。本自研方案补齐"实时广播"，并增加上传/限速/桌面壳。

## 已知限制

- 大文件夹 ZIP 打包在服务端同步完成，期间占一个线程（建议按子目录打包或单文件下载）。
- 移动端浏览器下载大文件受系统限制，属正常行为。
- 组播在 AP 隔离 WiFi 下不可达，此时手动输入地址访问（二维码仍可用）。
- 速度表依赖 SSE 统计推送，空闲 3 秒自动归零显示。
- 两台机器间发现需真实局域网验证（单机无法模拟组播回环，属预期）。

## 打包为 exe

```bash
py -m pip install pyinstaller
pyinstaller -F -w --add-data "static;static" --icon icon.ico --name 局域网快传 desktop.py
```

- `-w` 隐藏控制台；产物 `dist/局域网快传.exe`（约 206MB，QtWebEngine 体积较大；首次运行解压稍慢属正常）。
- exe 运行时 `config.json`、`downloads.json`、`icon.ico` 自动生成在 **exe 所在目录**（便携式，可拷给任意
  Windows 电脑使用，无需装 Python；下载统计随 exe 一起携带）。
- 每台电脑都装此 exe 即可互相同步；Windows Defender 首次运行可能提示，选择"仍要运行"。
