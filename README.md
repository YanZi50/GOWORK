# 局域网快传（LAN Share）

同一局域网内，把你的文件夹共享给别的电脑 / 手机，对方打开网页就能下载（或上传）。

纯内网传输，数据不出局域网。**不用装任何东西，双击即用。**

---

## 一、怎么启动（给你自己电脑用）

- **推荐**：解压 `dist\局域网快传 v2.4.zip`，双击里面的 `局域网快传.exe`（已打包，不需要装 Python，整个文件夹拷给别人即可）
- 或者双击 `启动桌面版.bat`（本机已装 Python 时可用）
- 首次启动约需 30-50 秒，属正常（第二次会快很多）
- 关闭窗口不会退出，程序会**最小化到右下角托盘**继续服务；双击托盘图标可重新打开主界面

## 二、怎么共享文件夹（给对方下载）

1. 打开主界面 → 点右侧「管理」
2. 点「添加共享」→ 填名称、选文件夹（或直接把文件夹拖进窗口，路径会自动填上）
3. 设置权限：
   - **公开**：任何人都能看和下载
   - **密码**：需要密码才能访问（自己编辑时能看到密码）
   - **仅自己**：只有你这台电脑能看
4. 勾选「可上传」可允许对方往这个文件夹传文件
5. 点「保存共享」——从这一刻起，文件夹才真正共享出去

## 三、别人怎么下载（对方电脑/手机）

1. 对方无需安装任何软件，用浏览器（电脑 Chrome / Edge，手机任意浏览器）打开：
   `http://你的电脑IP:8765`
   （你电脑上的界面里有二维码，对方扫码直达）
2. 如果开了密码，对方输入密码后即可进入
3. 点文件可**在线预览**（图片/视频/PDF/文本），点「下载」保存到本地；点「复制链接」可把直达链接发给别人

> 怎么看自己的 IP：主界面顶栏或「高级设置」里有显示。

## 四、常见问题

| 问题 | 解决办法 |
|---|---|
| 别人打不开页面 | 首次启动时 Windows 防火墙弹窗请选「专用网络」并允许；或检查是否在同一 WiFi |
| 设备互相看不到 | 路由器开了「AP 隔离」，进路由器设置关闭它 |
| 想开机自动启动 | 「管理」→「高级设置」→ 勾选「开机自启」 |
| 下载记录怎么看 | 「管理」→「下载记录」：显示谁下载过、几次、何时（设备名 + IP），避免误删还没被下载过的文件 |
| 下载的文件存哪了 | 「管理」→「高级设置」→「下载位置」设置保存目录；没设置时下载会提醒你先选一次（选后自动记住） |
| 换电脑/备份 | 把 `dist\局域网快传.exe` 拷走即可；`config.json`、`downloads.json` 在 exe 旁边（共享配置和下载记录） |
